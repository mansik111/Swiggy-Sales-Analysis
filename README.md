# Swiggy Sales Analysis 2025 | Python & Power BI

## 📌 Project Overview

This project focuses on analyzing Swiggy sales data for 2025 to understand revenue trends, food category performance, geographical sales distribution, and customer ratings.
Working with a dataset containing **197,430 orders**, I performed exploratory data analysis and created visualizations using Python in Jupyter Notebook. I then used the same dataset to build an interactive Power BI dashboard for a more effective and business-friendly presentation of the insights.
The project demonstrates how raw sales data can be transformed into meaningful insights through data analysis, visualization, and business intelligence.

## 🎯 Project Objectives

* Analyze sales and revenue trends across different time periods.
* Identify the highest revenue-generating food categories.
* Compare sales performance across states.
* Identify the top 5 cities based on revenue.
* Explore restaurant ratings and customer review counts.
* Create an interactive dashboard to present key business metrics and insights.

### Dashboard Visualizations

* **Monthly Sales Trend:** Tracks revenue performance across months.
* **Quarterly Sales Trend:** Compares sales across quarters.
* **Weekly Sales Trend:** Highlights week-wise revenue patterns.
* **Food Category Analysis:** Compares Veg and Non-Veg revenue.
* **State-wise Sales Analysis:** Shows revenue contribution by state.
* **Top 5 Cities by Revenue:** Highlights the highest-performing cities.
* **Ratings Analysis:** Helps explore ratings and customer review data.

### Why Power BI?

Interactive charts and KPI cards make it easier to identify trends, compare categories, and understand business performance without manually examining thousands of records. The dashboard provides a clear overview of the key metrics and helps users explore different aspects of the dataset.

## 💡 Key Business Questions

This project explores the following questions:

1. How does revenue change monthly, quarterly, and weekly?
2. Which days of the week generate the highest revenue?
3. Which food category contributes more to total sales: Veg or Non-Veg?
4. Which states generate the most revenue?
5. Which are the top 5 cities based on sales?
6. What do the ratings and customer review counts reveal about the dataset?
7. What key metrics help summarize overall sales performance?
